# UpSystem - versões publicadas

Repositório só de distribuição da atualização automática do UpSystem.
O arquivo `versoes/<canal>/upsystem-versao.json` diz qual é a versão atual e traz o SHA-256 do pacote; ele só vale acompanhado da assinatura `.sig`, conferida pelo sistema com a chave pública embutida.
Os pacotes (zip) ficam nos releases.
